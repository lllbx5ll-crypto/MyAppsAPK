# تطبيقاتي | My Apps — WebView APK

هذا المشروع يفتح موقع Blogger مباشرة:
https://appsyy.blogspot.com/?m=1

المزايا:
- صفحة Offline مخصصة بالعربية.
- زر إعادة المحاولة.
- زر الرجوع داخل WebView.
- التنزيلات عبر DownloadManager.
- الروابط الخارجية، ومنها MediaFire، تفتح في المتصفح.
- Splash/أيقونة قابلة للتعديل.
- لا توجد علامة مائية داخل التطبيق.
- تغييرات Blogger تظهر تلقائيًا لأن التطبيق يفتح الرابط المباشر.

البناء:
GitHub Actions موجود في .github/workflows/build.yml.
